What is this project?

This project connects a web chat interface to Firebase Realtime Database and a secure Firebase Cloud Function. The Cloud Function calls the OpenAI API without exposing the private API key in the browser.

How It Works

This app demonstrates four parts of an AI-powered web application:

1. Firebase Configuration

The browser connects to your Firebase project and listens for real-time messages.

2. Secure OpenAI Connection

The browser calls a Firebase Cloud Function; the OpenAI API key stays in Secret Manager.

3. Real-time Updates

Messages written by the Cloud Function appear automatically in the chat interface.

4. Session History

Each browser receives a random session ID stored locally, keeping histories separated.

Setup Required

The Firebase project information is already configured. Complete the server deployment steps in README.md.

1. Create a New OpenAI API Key

Do not place the key in this HTML or in chat-bot.js.

2. Save the Key as a Firebase Secret

Run firebase functions:secrets:set OPENAI_API_KEY in the project folder.

3. Deploy

Run firebase deploy --only functions,database,hosting.
