A web-based chat interface that can be opened directly from GitHub Pages.
What is this?

This demo stores its shared chat history in Firebase Realtime Database. OpenAI requests are sent through a Firebase Cloud Function, so the OpenAI API key is never included in the public GitHub files.

How It Works

1. GitHub Pages

Hosts the public HTML, CSS, and browser JavaScript files.

2. Firebase Realtime Database

Provides the live shared message history shown on the page.

3. Firebase Cloud Function

Receives the message, securely calls OpenAI, and saves both messages.

4. Secret Manager

Stores the OpenAI API key on the server instead of exposing it in GitHub.
